# Requisitos do Projeto — Estrela do Sul Website

## 1. Requisitos Funcionais (MVP)
- [ ] Landing Page institucional apresentando o Açougue Estrela do Sul.
- [ ] Hero section com proposta de valor e CTA direto para o WhatsApp.
- [ ] Seção "Sobre Nós" destacando tradição, qualidade e atendimento na Vila Ema.
- [ ] Catálogo visual de produtos organizado por categorias (Bovinos, Suínos, Aves, Linguiças/Preparados, Cortes Especiais, Ofertas).
- [ ] Destaque para ofertas da semana e cortes selecionados.
- [ ] Botões e links de conversão rápida via WhatsApp.
- [ ] Seção de localização com integração ao Google Maps (Av. Heitor Villa Lobos, 923 — Vila Ema, SJC).
- [ ] Exibição clara do horário de funcionamento (Seg–Sáb: 08:00–20:00 | Dom: 08:00–13:00).
- [ ] Footer institucional com informações de contato e endereço.

## 2. Requisitos Não Funcionais
- **Responsividade (Mobile-First):** Experiência otimizada para smartphones.
- **Performance:** Carregamento rápido e imagens otimizadas.
- **SEO Local:** Meta tags e estrutura semântica voltadas para buscas em São José dos Campos / Vila Ema.
- **Acessibilidade:** Contraste adequado, textos alternativos e navegação clara.
- **Manutenibilidade:** Código modular e tipado com React + TypeScript.
